# Pavel Kondrashov — личный сайт (SEO / GEO / AI-visibility)

Одностраничный сайт-визитка на **Next.js 16 (App Router) + TypeScript**. 3D-робот в hero-секции
следит за курсором головой, корпус наклоняется с задержкой, в покое — лёгкое покачивание, при
наведении мышью на робота — прищур.

## Стек

- **Next.js 16** (App Router, TypeScript strict)
- **Three.js** — робот собран из примитивов прямо в коде (без внешних моделей)
- **Чистый CSS** — вся тема и токены в `app/globals.css`
- **next/font** — Space Grotesk (заголовки) + Inter (текст, с кириллицей)

Зависимостей по минимуму намеренно — чтобы сборка была предсказуемой и без лишних точек отказа.

## Запуск локально

Нужен Node.js 20.9+ (рекомендуется 20 LTS или новее).

```bash
npm install
npm run dev      # http://localhost:3000
```

Прод-сборка:

```bash
npm run build
npm run start
```

## Деплой

**Vercel (проще всего):** залейте репозиторий на GitHub и импортируйте в Vercel — настройки
определятся автоматически (`next build`). Ничего настраивать не нужно.

**Свой сервер (Node):**

```bash
npm install
npm run build
npm run start    # поднимет прод-сервер на порту 3000 (PORT=80 npm run start — на 80-м)
```

Лучше за reverse-proxy (nginx) с HTTPS. Для автозапуска — pm2/systemd на `npm run start`.

## Где что править

- **Все тексты** — `lib/content.ts` (услуги, кейсы, метрики, процесс, FAQ, «обо мне», контакты).
- **Контакты** — там же: Telegram `@Pashagramm`, почта `kondraschov.pash@yandex.ru`.
- **SEO / мета-теги / JSON-LD** — `lib/seo.ts`. Поменяйте `site.url` в `lib/content.ts` на боевой
  домен — от него считаются canonical и OG-ссылки.
- **Цвета и тема** — CSS-переменные в начале `app/globals.css`.
- **Фото** — `public/about.jpg`. Кадрирование лица регулируется одной строкой в `globals.css`:
  `.avatar img { object-position: center 38%; }`.
- **Робот** — `components/hero/RobotCanvas.tsx` (геометрия, материалы, поведение, свет).

## Что стоит доделать перед продом

- Заменить плейсхолдеры в кейсах/метриках на реальные цифры (`lib/content.ts`).
- Поставить боевой домен в `site.url` и, при желании, добавить OG-картинку
  (положить файл в `public/` и указать `openGraph.images` в `lib/seo.ts`).
- Добавить `public/favicon.ico` и при необходимости `app/icon.png`.

## Заметки по реализации

- **Робот на «голом» Three.js**, а не React-Three-Fiber — чтобы не зависеть от совместимости
  R3F с React 19. Логика трекинга/анимации изолирована в одном клиентском компоненте; при желании
  переносится на R3F без изменения остального кода. Чтобы подставить вместо примитивов GLB-модель —
  загрузите её через `THREE.GLTFLoader` внутри `RobotCanvas.tsx` и навесьте те же группы
  (`headGroup` / `bodyGroup`) на узлы модели.
- **Space Grotesk без кириллицы** — поэтому русские заголовки рендерятся запасным Inter (это задано
  в `--font-head`). Если нужен «дисплейный» шрифт с кириллицей — замените Space Grotesk в
  `app/layout.tsx`.
- Анимации уважают `prefers-reduced-motion`; на тач-устройствах робот плавно водит головой сам.
